# Cards View & Date Filter
🔗 **Жива демо-версія:**https://nadiia29.github.io/test_project_webspark/

Невеликий фронтенд-проєкт із перемиканням вигляду карток (grid / list)  
та фільтрацією за датою.

## 🛠 Використані технології

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black)

## ✨ Функціональність

-   Перемикання вигляду карток: **плитка / рядки**
-   Вигляд **list** активний за замовчуванням
-   Коректна робота з `aria-pressed` (accessibility)
-   Фільтрація даних за діапазоном дат
-   Datepicker на базі **Flatpickr** з українською локалізацією

## 📌 Особливості реалізації

-   Чистий JavaScript без фреймворків
-   Явно заданий початковий стан інтерфейсу
-   Логіка перемикання винесена в окрему функцію
-   Код структурований і готовий до розширення
